# Supplementary materials

Supplementary files for **Thermal variation reveals contrasting germination patterns among rupestrian grassland bromeliads**, submitted to *Seed Science Research* and presented in Annex D of the doctoral thesis.

- [Tables S1–S7 (Excel)](SEEDS_SUPLEMENTAR.xlsx)
- [Figure S1 (PDF)](FigS1.pdf)
- [Figure S1 (PNG)](FigS1.png)

The workbook contains replicate-level germination traits and curve fits (S1), thermal-curve input means (S2), descriptive summaries (S3), model coefficients (S4), model predictions (S5), extrapolated thermal limits (S6), and day-14 operational performance (S7).

Figure S1 presents pairwise species comparisons as odds ratios with 95% confidence intervals at 21, 24.5 and 30.5 °C.

These are unchanged copies of the files prepared for submission. No statistical analysis was rerun for this deposit. Analysis code and raw experimental records are not included.
